From **Add funds**, choose **Crypto**, then select the asset you want to deposit.

  width="320"
/>

## Deposit USDC (Cash)

1. Select **Cash**.
2. Choose the network you will send USDC on.
3. Copy the wallet address or scan the QR code, then send USDC from your wallet or exchange.

<img
  src="/depositing-crypto/choose-network-usdc.jpg"
  alt="Choose network for USDC deposit"
  width="320"
/>

Make sure you send USDC on the **same network** you selected in Axal. Sending on the wrong network can result in lost funds.

Supported networks include Arbitrum, Monad, Ethereum, Base, and Polygon.

## Deposit BTC

1. Select **Bitcoin**.
2. Choose how you want to receive Bitcoin (Cash App, native Bitcoin, or Base / cbBTC).
3. Copy the address or invoice details shown, then send from your wallet or app.

<img
  src="/depositing-crypto/receive-bitcoin.jpg"
  alt="Receive Bitcoin via Cash App, native BTC, or Base"
  width="320"
/>

Bitcoin can arrive from **Cash App** (Lightning invoice), as **native BTC**, or as **cbBTC on Base**. Use the option that matches where you are sending from.

Make sure the network or method you pick in Axal matches the one you send on. Sending on the wrong network can result in lost funds.

## Troubleshooting

- Deposit not showing? Wait a few minutes for the transfer to confirm, then refresh your balance.
- Sent on the wrong network? Contact support at [hello@getaxal.com](mailto:hello@getaxal.com) with the transaction hash so the team can advise on recovery options.
